О приложении

Веб-приложение для учёта покупок и расчёта их стоимости разработано в рамках курсового проекта.

Разработчик

Пестряков Никита Максимович, группа РИЗ250213у. УрФУ, 2026 год.

Возможности

Просмотр и ведение покупок и магазинов, проверка бюджета по сохранённым покупкам, регистрация и вход. READ_ONLY разрешает просмотр, USER работает со своими записями, ADMIN — со всеми данными и ролями.

Технологии: Java 17, Spring Boot 2.7.8, Spring Security, Spring Data JPA, Thymeleaf, Lombok и H2.
